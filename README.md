# Burning Memory: Nostalgia Puzzle Adventure (Demo Outline)

A narrative-forward puzzle adventure set in the everyday world, celebrating late 90s and early 2000s nostalgia. Siblings **Zander** and **Jackie** search for Jackie's missing handheld console. A secretive community guides them through puzzles rooted in retro tech, media, and family artifacts. This repository contains a demo outline with chapter beats, mechanics, and flavor intended for a vertical slice.

- **Setting:** Suburban present-day neighborhoods, thrift shops, music rooms, and family homes. No portals, no boss fights—just people, puzzles, and memories.
- **Tone:** Warm, curious, slightly uncanny but grounded. Humor and heart outweigh danger.
- **Core Pillars:**
  - Celebrate tactile nostalgia (Polaroids, VHS, mixtapes, Furbies, LAN parties).
  - Keep puzzles human-driven; helpers are eccentric, not supernatural.
  - Encourage collaborative play between siblings: Jackie experiments, Zander observes.

See `docs/nostalgia_demo_outline.md` for the chapter breakdown and puzzle details.
